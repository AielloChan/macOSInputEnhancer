# macOS 標準入力メソッド拡張

辞書ファイルを macOS 標準入力メソッドで利用できるようにインポートします。

iOS と macOS に標準搭載されているユーザ辞書機能を利用して辞書を拡張します：https://support.apple.com/ja-jp/guide/iphone/iph6d01d862/ios

現在の対応状況：
- **機能**
  - [x] すべてのファイルを取得
  - [x] 単一ファイルをデコードしてすべての語句を出力
  - [x] 語句を読みへ変換
  - [x] 入力メソッドプラグインに対応
  - [x] キーと語句のペアを生成
  - [x] クライアント用ファイルを出力
  - [x] オブジェクト形式の呼び出しに対応
  - [x] 指定範囲のデータ出力に対応
  - [x] 設定ファイルへの Example 辞書の注入
  - [x] 既存辞書とのマージに対応
- **入力形式**
  - [x] Sogou セル辞書（.scel）
  - [x] プレーンテキスト
  - [x] macOS 標準入力メソッドの plist
- **変換方式**
  - [x] 小鶴双拼（Xiaohe Double Pinyin）
- **出力形式**
  - [x] macOS 標準入力メソッドの plist

基本機能は完成しており、Sogou セル辞書（.scel）を macOS 標準入力メソッドへインポートできます。

## 使い方

1. https://pinyin.sogou.com/dict/ からインポートしたいセル辞書（.scel）をダウンロードします。
2. `resources/scel` ディレクトリに配置します。先頭が `_` のファイルと、拡張子が `.scel` でないファイルは自動的に無視されます。
3. `yarn` または `npm install` ですべての依存関係をインストールします。
4. `yarn run build` または `npm run build` で変換とビルドを実行します。
5. 成功すると、`output` ディレクトリに `plist` ファイルが生成されます。
6. macOS の「システム設定」→「キーボード」→「ユーザ辞書」を開き、`plist` ファイルをリストへドラッグします。

## !!! 重要な注意事項 ⚠️ !!!

この方法でインポートすると、既存のユーザ辞書が直接上書きされます。事前に必ずバックアップしてください。すべての項目を選択して任意のフォルダへドラッグすると、plist ファイルとして書き出せます。

一度に大量の辞書を追加しないでください。最初に 2 万件で試したところ、Mac が完全に応答しなくなりました。その場合は項目を削除して再起動してください。macOS は大量のユーザ辞書項目に対して十分に最適化されていないようです。

最初は 2,000 件だけ追加することを推奨します。

## カスタマイズしたい開発者向け

エントリーファイルは `index.js` です。

設定ファイルの形式：
```javascript
{
  // スキャン対象のディレクトリ（サブディレクトリはスキャンしません）
  // すべてのファイルの絶対パスを配列で返します
  inputs: ['./resources/txt'],
  // ファイル形式に応じて適切なローダーを自動選択します
  // すべての語句を配列で返します（例：`["你好","今天"]`）
  loaders: [loaders.TxTLoader()],
  // 上記の配列を処理するプラグイン（重複排除、並べ替え、追加、削除など）
  // 処理後の新しい配列を返します
  plugins: [
    // 開発モードでは UseExample プラグインを使用します
    // それまでの語句データをテストデータで置き換えます
    IS_DEV ? UseExample(EXAMPLE_DATA) : null,
    // 語句から中国語以外の文字を削除します
    HanziOnly(),
    // 重複を削除します
    Uniq(),
    // 指定件数をランダムに選択します
    RandomN(2e3),
    // 既存データを追加してマージします
    AddWords(userDic),
  ],
  // 入力方式に応じて語句をキー入力へ変換します
  // 同じ語句でも、拼音、双拼、五筆ではキーマッピングが異なります
  // ここでは小鶴双拼トランスフォーマーを使用します
  transformer: transformers.XiaoheTransformer(),
  // 語句とキーを対象プラットフォームのファイル形式へ変換します
  // ここでは macOS 標準入力メソッドのユーザ辞書として出力します
  adapter: adapters.macOSRender(),
  // 出力ファイルの保存先
  output: './output/macOS_input_dic.plist',
  // コマンドラインへログを出力するかどうか
  log: true,
}
```

設定ファイルの処理順序は固定されており、逆順や入れ替えはできません：

`inputs` -> `loaders` -> `plugins` -> `transformer` -> `adapter` -> `output`

- loaders：各ファイル形式を読み込みます。引数は「単一ファイルの絶対パス」、戻り値は語句の配列です（例：`["你好","今天"]`）。
- plugins：語句の配列を受け取り、処理後も同じ形式の配列を返します。たとえば `"你好"` を除外すると `["今天"]` を返します。
- transformer：語句を `[你好, nihc]` のような配列へ変換します。
- adapter：データを各プラットフォーム互換の形式へ変換します。
