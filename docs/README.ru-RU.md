# Расширение встроенного метода ввода macOS

Импортируйте файлы словарей для использования со встроенным методом ввода macOS.

Для расширения словаря проект в основном использует встроенную в iOS и macOS функцию замены текста: https://support.apple.com/ru-ru/guide/iphone/iph6d01d862/ios

Текущая поддержка:
- **Функции**
  - [x] Получение всех файлов
  - [x] Декодирование одного файла и вывод всех фраз
  - [x] Преобразование фраз в произношение
  - [x] Интеграция плагинов методов ввода
  - [x] Создание пар «клавиши — фраза»
  - [x] Вывод клиентских файлов
  - [x] Объектный способ вызова
  - [x] Вывод данных из заданного диапазона
  - [x] Внедрение словаря Example в конфигурацию
  - [x] Объединение с существующими словарями
- **Форматы ввода**
  - [x] Ячеистый словарь Sogou (.scel)
  - [x] Обычный текст
  - [x] Формат plist встроенного метода ввода macOS
- **Преобразование**
  - [x] Xiaohe Double Pinyin
- **Форматы вывода**
  - [x] Формат plist встроенного метода ввода macOS

Основные функции готовы. Поддерживается импорт ячеистых словарей Sogou (.scel) во встроенный метод ввода macOS.

## Использование

1. Скачайте нужный ячеистый словарь (.scel) с сайта https://pinyin.sogou.com/dict/
2. Поместите его в каталог `resources/scel`. Программа автоматически игнорирует файлы, имена которых начинаются с `_`, а также файлы без расширения `.scel`.
3. Установите все зависимости командой `yarn` или `npm install`.
4. Запустите преобразование и сборку командой `yarn run build` или `npm run build`.
5. После успешного выполнения файл `plist` появится в каталоге `output`.
6. Откройте «Системные настройки» → «Клавиатура» → «Замена текста» и перетащите файл `plist` в список.

## !!! Важное предупреждение ⚠️ !!!

Этот способ импорта напрямую заменяет существующие записи замены текста. Сначала создайте резервную копию: выделите все записи и перетащите их в любую папку, чтобы экспортировать файл plist.

Не добавляйте слишком много словарей за один раз. Во время первого теста с 20 тысячами записей компьютер полностью завис. Чтобы исправить это, удалите записи и перезагрузите компьютер. Похоже, macOS недостаточно оптимизирована для большого количества записей замены текста.

Для первой попытки рекомендуется добавить не более 2 000 записей.

## Для разработчиков, которые хотят доработать проект

Точка входа — файл `index.js`.

Формат файла конфигурации:
```javascript
{
  // Каталог для сканирования (подкаталоги не сканируются)
  // Возвращает массив абсолютных путей ко всем файлам
  inputs: ['./resources/txt'],
  // Автоматически выбирает загрузчик для соответствующего формата файла
  // Возвращает массив всех фраз, например `["你好","今天"]`
  loaders: [loaders.TxTLoader()],
  // Обрабатывает предыдущий массив: удаляет дубликаты, сортирует, добавляет или удаляет данные
  // Возвращает новый массив
  plugins: [
    // В режиме разработки используется плагин UseExample
    // Он заменяет все предыдущие записи тестовыми данными
    IS_DEV ? UseExample(EXAMPLE_DATA) : null,
    // Удаляет из записей все символы, не являющиеся китайскими
    HanziOnly(),
    // Удаляет дубликаты
    Uniq(),
    // Случайно выбирает указанное число записей
    RandomN(2e3),
    // Добавляет и объединяет существующие данные
    AddWords(userDic),
  ],
  // Преобразует фразы в нажатия клавиш в соответствии с методом ввода
  // Для одной фразы Pinyin, Double Pinyin и Wubi используют разные сочетания клавиш
  // Здесь используется преобразователь Xiaohe Double Pinyin
  transformer: transformers.XiaoheTransformer(),
  // Преобразует фразы и клавиши в формат указанной платформы
  // Здесь создаются пользовательские фразы встроенного метода ввода macOS
  adapter: adapters.macOSRender(),
  // Путь для сохранения выходного файла
  output: './output/macOS_input_dic.plist',
  // Выводить ли журналы в командную строку
  log: true,
}
```

Порядок обработки в конфигурации фиксирован, его нельзя инвертировать или менять:

`inputs` -> `loaders` -> `plugins` -> `transformer` -> `adapter` -> `output`

- loaders: загружает разные форматы файлов. Параметр — `абсолютный путь к одному файлу`, результат — `массив фраз`, например `["你好","今天"]`.
- plugins: принимает массив фраз, например `["你好","今天"]`, и после обработки возвращает массив того же формата. Например, при фильтрации `"你好"` результатом будет `["今天"]`.
- transformer: преобразует фразы в массивы вида `[你好, nihc]`.
- adapter: преобразует данные в форматы, совместимые с разными платформами.
